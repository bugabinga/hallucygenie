# The Purpose of this project

Expose the MiniMax API in a web UI.
Agentic and kid-friendly.
Fun and gaming culture adjacent.
Kid creates media assets for use in YouTube videos.
Kid talks to the machine for ideas, guidance, help and execution of MiniMax API
calls.
App presents simple agentic loop with tools, skills and prompts.
All complexity hidden from kid.
Tools, skill and prompts are built-in.
